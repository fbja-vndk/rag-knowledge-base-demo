# RAG Knowledge Base Demo
A lightweight Retrieval-Augmented Generation (RAG) system for private knowledge base question answering.

## Features
- Document parsing and text chunking
- Vector storage and semantic retrieval
- LLM-based answer generation
- Support for multiple document formats

## Tech Stack
- Python
- LangChain
- Chroma / Milvus vector database
- Open-source large language models

## Purpose
This project is used for RAG technology validation and cloud inference deployment testing.
